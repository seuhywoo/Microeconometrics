DW Propensity Score Notes

What the Dehejia–Wahba (1999, 2002) propensity scores must look like to reproduce the published CPS numbers.

1. The 1999 score JASA, Table 3 footnote (g)

  • If we estimate the score exactly as footnote (g) lists it, two numbers in the Figure 2 caption are far off:
    • discarded CPS units: 12,136 vs. 12,611
    • CPS units in the first bin: 3,454 vs. 2,969
  • The counts with ê > 0.8 are close either way: 36 treated / 8 comparison vs. 35 / 7.
  • If we drop nodegree, the caption is matched exactly: 12,611 discarded, 2,969 in the first bin, 7 comparison units above 0.8. Only the treated count above 0.8 is off by one (34 vs. 35).
  • The same score also reproduces the Table 3 matching ATT exactly: 1,582.
  • Two numbers are not matched by either spec:
    • Table 3, column (6) observations: paper 4,117; footnote (g) 4,041; without nodegree 3,566.
    • Table 4, MCPS-1 observations: paper 119; footnote (g) 106; without nodegree 112.

2. No-constant logit ReStat 2002

  • A logit with no constant, with U74 / U75 coded as “1 if positive earnings” (see section 3), reproduces the 2002 CPS results exactly:
    • Figure 1 caption: 11,168 discarded, 4,398 in the first bin
    • Table 2, nearest-neighbor matching: 119 observations
    • Table 2, caliper matching: 325 / 1,043 / 1,731 observations
    • Table 2 treatment effects: 1,605 / 1,559 (without replacement), 1,360 (nearest neighbor), 1,119 / 1,158 / 1,122 (caliper)

  • With a constant, none of these numbers are reproduced.
  • DW (2002) never says it drops the constant. The appendix writes the model as eλh(X) / (1 + eλh(X)) with no explicit intercept, but that alone is not real evidence.
  • Smith and Todd (2005, p. 328) confirm it directly: “although DW (2002) did not include a constant term in the logistic model, we do.” So the no-constant logit is documented in the literature, not only inferred from our replication.
  • Dropping the constant is equivalent to restricting the intercept to β74 + β75 in the model that uses the zero-earnings coding. A likelihood ratio test rejects this restriction strongly: LR ≈ 80, df = 1.
  • So the no-constant logit is what DW (2002) did, but it is not a justified modeling choice. We use it only to reproduce the 2002 numbers.

3. U74 / U75 coding ReStat 2002

  • The paper defines U74 (U75) as “1 if unemployed in 1974 (1975), 0 otherwise.”
  • The data have no employment status variable, so “unemployed” can only mean zero earnings.
  • But the means in Table 2 (CPS) match the share with positive earnings: 0.29 / 0.40 for NSW and 0.88 / 0.89 for the full CPS. So in Table 2 the variable is really “1 if positive earnings in 1974 (1975), 0 otherwise.”
  • This coding changes the score only when the logit has no constant. With a constant, both codings give the same score. So it does not affect the 1999 Table 3 replication.

4. Applying the 2002 score to 1999 Table 3 CPS-1 row

  • Question: if we use the score that reproduces the 2002 paper, do we get the 1999 Table 3 estimates?
  • Answer: no. The 2002 score moves every score-based column further from the 1999 paper than the 1999 score does.

  • So a score that reproduces the 2002 paper must give 1,360 in column (7), not 1,582. A score that fits 2002 cannot fit 1999 on this data.
  • Matching the mean score alone also does not pin down the spec: many specs with two or three terms dropped give a treated mean near 0.37, and their ATTs differ.
  • For 1999 Table 3 we therefore use the spec found from the 1999 paper's own evidence (Figure 2 caption and column (7) = 1,582).
  • This gap is itself a result: the authors' own two papers show how sensitive the matching ATT is to the score specification, which is the point Smith and Todd (2005) make.

Conclusion: the 1999 and 2002 papers used different propensity scores. For 1999 Table 3, we use the logit with a constant and without nodegree.
